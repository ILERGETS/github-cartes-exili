# Cartes de l'exili

Llibre-regal a partir de 44 cartes i postals de l'exili (1938–1945) dels avis **Valentín Granada** i **Presentación Gracia**, exiliats a Fleurance (Gers, França), escrites a la família que va restar a Espanya.

Autor/editor familiar: **Josep Lluís Puyalto Granada**.

## Contingut
- **`Cartes de l'exili - interactiu.html`** — llibre interactiu (un sol arxiu, amb les imatges a dins). 4 llengües: català, castellà, francès i polonès.
- **`Cartes de l'exili - Llibre-cat-v02.pdf`** / `-cast-` / `-fr-` / `-pl-` — el llibre en PDF, una per llengua.

## Com obrir-lo
1. Descarrega **tota la carpeta** (o el repositori sencer).
2. Obre `Cartes de l'exili - interactiu.html` amb Chrome, Safari o Edge.
3. El botó d'impressió i els botons de PDF funcionen perquè els 4 PDF són en la **mateixa carpeta** que l'HTML (no els separis).

## Notes
- Repositori **privat** (material personal; hi ha parents vius).
- Les traduccions al francès i al polonès són esborrany per revisar.
