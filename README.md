# Cartes de l'exili

Llibre-regal a partir de 44 cartes i postals de l'exili (1938–1945) dels avis **Valentín Granada** i **Presentación Gracia**, exiliats a Fleurance (Gers, França), escrites a la família que va restar a Espanya.

Autor/editor familiar: **Josep Lluís Puyalto Granada**.

## Com obrir el llibre
Obre directament aquest enllaç al navegador (mòbil, tauleta o ordinador):

**https://ilergets.github.io/github-cartes-exili/**

- Es veu el llibre interactiu complet (4 llengües: català, castellà, francès i polonès).
- Des del botó d'impressió pots descarregar el PDF de cada llengua.

## Contingut del repositori
- `index.html` — el llibre interactiu (un sol arxiu, amb les imatges a dins).
- `cartes-exili-cat.pdf` / `-cast` / `-fr` / `-pl` — el llibre en PDF, una per llengua.

## Nota
- Les traduccions al francès i al polonès són esborrany per revisar.
